# 说明 · 混元 3D 生成道具模型（AI意识视频）

你只负责用腾讯混元 3D 生成下面 3 个 3D 模型，下载成 GLB 文件，打包交回。这些模型会放进 Blender 场景里，替换原来用方块拼的道具。

## 在哪里生成

腾讯混元 3D 网页版（用浏览器打开，用微信或 QQ 登录）。每天有免费次数，3 个模型够用。

## 步骤

1. 选「文生 3D」（用文字生成）。
2. 把下面每条的提示词原样复制进去，生成。
3. 生成好后，转着看一下：形状对、没有明显缺块就行，不用挑。实在不像，重新生成一次。
4. 下载格式选 **GLB**（带贴图）。如果有「面数 / 精度」选项，选中等或较低就行，不用最高。
5. 文件改名成下表里的名字。

| 文件名 | 提示词（直接复制） |
|---|---|
| 灯泡.glb | 一个老式透明玻璃白炽灯泡，螺口金属灯头，能看到里面弯曲的钨丝，写实风格，单个物体 |
| 人脑.glb | 人类大脑解剖模型，从侧面能清楚看到后下方的小脑和脑干，写实风格，单个物体 |
| 显示器.glb | 一台现代电脑显示器，黑色细边框，带支架和底座，屏幕是黑的，写实风格，单个物体 |

## 注意

- 画面里只要这一个物体，不要地面、不要背景、不要文字。
- 生成失败或下载不了的，在「说明.txt」里写一句，其余照常交回。

## 交回

3 个 GLB 文件 +（如果有）说明.txt，打成 `AI意识_道具回传.zip`。

打包好后，用电脑上的 QQ 打开「我的手机」（我的Android手机 / 我的iPhone）对话，把这个压缩包发过去，发到我的手机 QQ 上。压缩包太大发不了，就分卷压缩成几个包分别发。
